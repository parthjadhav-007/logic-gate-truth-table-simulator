# Logic Gate Truth Table Simulator

A small Python project that evaluates Boolean expressions and prints their truth tables. It also displays the truth tables for the standard two-input gates.

## Features

- Supports `AND`, `OR`, `NOT` and `XOR` expressions.
- Accepts variable names such as `A`, `B` and `X1`.
- Generates up to eight input variables in a truth table.
- Includes a `gates` command for AND, OR, XOR, NAND, NOR, XNOR and NOT.

## Requirements

- Python 3

## Run

```bash
python logic_gate_simulator.py
```

Enter an expression such as `(A AND B) OR (NOT C)`. Type `gates` to view the standard gate tables, or `quit` to exit.

This is a learning project for practising Boolean logic and Python input, loops, lists and dictionaries.
